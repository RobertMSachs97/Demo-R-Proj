The repository is the source code used for the following presentation:

https://docs.google.com/spreadsheets/d/1zox3nJ-nQlnZleZITASFjCZfrgiAM6GG6F6X6F5R4ZE/edit?usp=sharing

Each file is written to run on my machine only, with the data input path hard coded into the script obesity_data_in.R. The scripts are not glued together anywhere and are intended to be run manually by themselves. Finally, obesity_data_in.R contains many lines that were run specifically to examine the csv written in to the code.

If you did want to run the code on your own machine, it would be best to create an R program that would output data frames with the same names variable counts as the data frames in the obesity_data_in.R. You would then need to run the functions.R file in order for the other scripts to work. Keep in mind that none of the scripts were written to accept data frames not created by obesity_data_in.R.

All of this is due to this repository only being intended as an explanation of the methodology and editing used for the above Google sheets presentation.
